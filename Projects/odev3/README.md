# odev3

Ödev 3: [DesignWorks](../DesignWorks) çalışmasının avokado ürün sayfasına uyarlanmış hâli.

**Açmak için:** `odev3.xcodeproj` → Xcode → ▶︎

- Aynı mantık: Assets renkleri, özel font (`Isometra-Regular`), `Localizable.strings` ile TR/EN, `GeometryReader`, `UINavigationBarAppearance`.
- **DesignWorks'ten fark:** `Chip` bileşeni `LocalizedStringKey` kullanıyor, bu yüzden "organik / taze / yerli / vegan" etiketleri cihaz diline göre çevriliyor.
- Resim: `avacado`.
